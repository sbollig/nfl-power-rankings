# NFL Power Rankings 2026

A single static page that documents the logic in ΖΓ559's weekly NFL spreadsheet: how a neutral-field rating per team plus a home-field number becomes a projected spread, and how that spread is compared with the sportsbook line. On top of that it adds a simple week-to-week rating update and a scorecard.

Open `index.html` or visit the published page.

No server code, no cookies, no analytics. For entertainment only; not betting advice.

Scores: ESPN scoreboard. Ratings and home-field values are ΖΓ559's own numbers, not independently verified.
